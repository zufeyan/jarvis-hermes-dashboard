# คู่มือใช้งานประจำวัน — JARVIS Thai Voice + Chat (v pilot)

## เริ่มใช้งาน (คำสั่งเดียว)
```sh
cd /Volumes/Data_Sufayan/git_project/jarvis-hermes-dashboard
python3 start-thai.py --no-browser
```
เปิด http://127.0.0.1:8730 ใน Chrome/Edge/Safari บนเครื่องเดียวกัน (ผูกเฉพาะ loopback ไม่รับจาก LAN) · กด **Ctrl/Cmd+R** ทุกครั้งหลังรีสตาร์ตเซิร์ฟเวอร์เพื่อรับ token ใหม่ · หยุดด้วย `Ctrl+C`

## ขั้นตอนใช้งานจริง
1. กด **● กดเพื่อพูด** → อนุญาตไมค์ → พูดภาษาไทย/ไทยปนศัพท์ IT → กด **หยุดบันทึก**
2. รอถอดเสียง (local Whisper `medium`/`th` — ค่าเฉลี่ย ~7 วิ p95 ~11 วิ) → **ตรวจ/แก้ข้อความ** ที่ช่องบน
3. กด **ใช้ข้อความถอดเสียงในแชต** (ยังไม่มีการส่งอัตโนมัติ)
4. ดูแถบสีส้มใต้ช่องข้อความ — ระบบจะ **list ตัวเลข/IP/CIDR/ชื่อบัญชี ที่ต้องตรวจ** ให้อัตโนมัติ (เช่น `192.168.10.5 · /26 · admin01 · 24`) และปุ่มจะเปลี่ยนเป็น “ยืนยันส่งข้อความให้ Hermes · ตรวจตัวเลข N รายการ” — ตรวจด้วยตาจนครบแล้วจึงกดยืนยัน
5. รอคำตอบ (โมเดลปัจจุบัน `xiaomi / mimo-v2.6-flash` ~5–15 วิ) ข้อความแสดงบนหน้าจอ
6. ถ้าคำตอบต้องอ่านไฟล์จริง ระบบจะขึ้น **แผง “ต้องการอนุมัติการอ่านไฟล์”** แสดงชื่อไฟล์/arguments/เวลาหมดอายุ (90 วินาที) — กด **อนุมัติอ่านครั้งนี้** จึงจะอ่าน และระบบจะอ่านไฟล์นั้นเท่านั้นในโฟลเดอร์ที่อนุญาตเท่านั้น
7. กด **อ่านคำตอบ** เพื่อฟังเสียงไทย Edge `th-TH-NiwatNeural` (กดซ้ำได้ถ้าเบราว์เซอร์บล็อกครั้งแรก) · **หยุดเสียงอ่าน** เพื่อหยุด
8. **เริ่มบทสนทนาใหม่** = ล้างประวัติและคำขออนุมัติของแท็บนั้นเท่านั้น

## เปิด/ปิดอะไรอยู่
| เปิด | ปิด (fail-closed) |
|---|---|
| ถอดเสียงไทยในเครื่อง (ไม่ส่งเสียงออก) | เครื่องมือ Hermes ทุกชนิด: terminal/เบราว์เซอร์/delegation/เขียนไฟล์ (มีเฉพาะ read-only 2 ตัว ที่ต้องอนุมัติรายครั้ง) |
| สนทนากับ Hermes แบบ **chat-only** | `/api/jobs`, คำสั่ง slash, การแก้ระบบ/ส่งอีเมล |
| อ่านเสียง Edge (ออนไลน์ ไม่ต้อง API key) | LAN/tunnel/autostart/wake word/ฟังตลอดเวลา |
| ยกเลิกงาน + กันคำตอบเก่า/กันส่งซ้ำ | session เดียวกับ Hermes Desktop (คนละกัน) |

## ข้อจำกัดที่ต้องรู้
- **อย่าพิมพ์/ส่งข้อมูลลับ** — ข้อความที่ยืนยันส่งจะไปยังผู้ให้บริการโมเดลที่ตั้งไว้ และข้อความที่กดอ่านจะส่งไป Edge ออนไลน์
- ตัวเลข/IP ยังไม่เชื่อถือ 100% จากชุดทดสอบ 30 วลี: slot แบบเข้มผ่าน 1/5 (จุดใน IP หาย, `/26` หาย, `admin01` ถูกถอดเป็นคำไทย) → **ตรวจก่อนกดยืนยันเสมอ** ห้ามเดาหรือปล่อยผ่าน
- โมเดลถอดเสียงยังเป็น `medium` (คุณภาพดีกว่า `small`: CER 0.172 เทียบ 0.260) แม้ช้ากว่าเป้า — ถ้าอยากได้ความเร็ว p95 ~3.2s ให้สลับเป็น `small` ตาม `model_compare_report.md` (มี backup/rollback ทุกครั้ง)
- ประวัติแชตเก็บใน RAM รายแท็บ — รีสตาร์ตแล้วหาย (ยังไม่มีแบบถาวร)
- เสียงตอบ/การยกเลิก: ปุ่มหยุดเล่นได้ทันที แต่งานฝั่งเซิร์ฟเวอร์/ค่า usage ของ provider อาจยังเดินต่อจนจบ
- นี่ยัง **ไม่ใช่** ระบบสั่งงานเต็มรูปแบบ — การสั่งจริงใช้ Hermes Desktop

## ฟีเจอร์เสริม (opt-in — ทุกอันปิดเป็นค่าเริ่มต้น)
รายละเอียดและหลักฐานจริงทั้งหมดอยู่ที่ `docs/POST_V1_OPTIN_TH.md`
| ต้องการ | คำสั่ง |
|---|---|
| เข้าจากมือถือ/เครื่องอื่นในบ้าน | `python3 start-thai.py --no-browser --lan --lan-allow "192.168.x.x"` |
| เปิดเองเมื่อเข้าสู่ระบบ | `python3 autostart.py install` (`uninstall` เพื่อลบ) |
| ให้จาร์วิสเขียนไฟล์/รันคำสั่งใน sandbox | ตั้ง `tools_layer_b.json` → `enabled: true` + `sandbox_root` (ยังคงต้องกดอนุมัติทุกครั้ง) |
| เรียกด้วยเสียง “จาร์วิส …” | `python3 wakeword.py` (ต้องมี server รันอยู่ก่อน, Ctrl-C หยุด) |

## แก้ปัญหาที่พบบ่อย
| อาการ | สาเหตุ | ทำอย่างไร |
|---|---|---|
| ขึ้น “จาร์วิสพยายามใช้เครื่องมือนอกขอบเขต ระบบจึงปฏิเสธไว้ก่อน” | คำขออ่านไฟล์อยู่นอก allowlist — **ไม่ใช่ข้อผิดพลาด** และไม่มีไฟล์ถูกอ่าน | ถามเรื่องที่อยู่ในโฟลเดอร์ที่อนุญาต (ข้อความจะบอกชื่อโฟลเดอร์ให้) หรือให้ Jarvis เพิ่มโฟลเดอร์ใน `tools_gate.json` → `roots` แล้วรีสตาร์ต |
| `สนทนาไม่สำเร็จ: โหมดโมเดลติดโควตา (HTTP 429)` | `openai-codex` default ติด usage limit (ถึง ~13 ต.ค. 10:57) | ไม่ต้องทำอะไร ระบบใช้ `chat_route.json` → `xiaomi/mimo-v2.6-flash` อยู่แล้ว; ถ้าลบไฟล์นั้นจะกลับไปติด 429 |
| ปุ่มอ่านขึ้น “เบราว์เซอร์บล็อกการเล่น…” | autoplay policy | กด **อ่านคำตอบ** อีกครั้ง — จะเล่นเสียงเดิมทันทีไม่ต้องสร้างใหม่ |
| ปุ่มส่ง/อ่านเป็นสีเทา | ยังไม่มีคำตอบ หรือกำลังอัด/ถอดเสียง | ดูบรรทัดสถานะใต้ช่อง — บอกเหตุผลเป็นไทยทุกครั้ง |
| หน้าโหลดแล้วไม่ยอมส่ง | token เปลี่ยนหลังรีสตาร์ต | รีเฟรชหน้า (`Ctrl/Cmd+R`) |
| ถอดเสียงผิดบ่อยกับคำศัพท์เฉพาะ | โมเดล `medium` + prompt | แก้ด้วยมือก่อนส่ง (ออกแบบมาให้ตรวจทาน ไม่ใช่ส่งอัตโนมัติ) |
